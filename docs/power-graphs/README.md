## Naming

```text
<voltage>v.png                  default capture
<voltage>v-0.78.png             IMU wake, 0.78 Hz profile
<voltage>v-0.png                backlight 0 %
<voltage>v-50.png               backlight 50 %
<voltage>v-100.png              backlight 100 %
```

## Rules

- One capture per test item, voltage and variant.
- The value quoted in the reports is the `WINDOW Avg` of the same capture.
- Crop only to keep the legend; do not rescale or retouch the plot area.
